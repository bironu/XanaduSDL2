# *** あるいはあなたはこのファイルを読むべきではありません ***
#
# ファイル書式:
# 隠し名前を持つキャラクターは、空行と空行との間にある
# タグで始まる行の並びによって定義されます。
# 最初のタグで始まる行のタグは Name: でなければなりません。
# # で始まる行全体は空行として扱われます。
#
# データ形式:
# 文字列	"(二重引用符)で囲まれた英数字・記号・空白の最大14個の並び。
# 数値		数字の並び。
# 文字列*数値	持ち物の数を指定するときに使う形式。
#
# タグの種類: 指定しないエントリはデフォルトのままです。
# タグ		形式		意味
# ----------------------------------------------
# Name:		文字列		名前
# HP:		0-6553500	ヒットポイント
# Gold:		0-6553500	お金
# Food:		0-6553500	食料
# STR:		0-255		強さ
# INT:		0-255		知識
# WIS:		0-255		賢さ
# DEX:		0-255		器用さ
# AGL:		0-255		敏捷さ
# CHR:		0-255		魅力
# MGR:		0-255		魔法抵抗力
# KRM:		0-255		カルマ
# ELX:		0-255		霊薬
# KEY:		0-255		鍵
# CRN:		0-255		王冠
# Weapon:	文字列		装備している武器
# Scroll:	文字列		装備している魔法
# Armor:	文字列		装備している鎧
# Shield:	文字列		装備している盾
# Item:		文字列		装備している道具
# Inventory: 文字列*0-255, ...	所持品
#
# デフォルトキャラクター:
# HP:		1500
# Gold:		3500
# Food:		 100
# STR..CRN:	   0
# Weapon:	"Dagger"
# Scroll:	"Needle"
# Armor:	"Cloth"
# Shield:	"Gloves"
# Item:		"Spectacles"
# Inventory:	"Spectacles"*10, "Red Potion"*1
#
# シナリオ間で異なるアイテム名の扱い:
# 例えば、
# Weapon: "Morning-Star"
# だと、シナリオ1にしか適用されません。
# どちらのシナリオにも持っていきたい場合は、両方書いてください。
# Weapon: "Morning-Star"
# Weapon: "Heavy-Spear"
# とか
# Inventory: "Balance"*10, "Silver Rose"*10
#
